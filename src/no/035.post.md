A researcher at Vrije Universiteit Amsterdam did something that most AI evaluations skip: he tested fifteen AI literature search tools against a known answer. His team had already found 48 replications of a set of experiments on charitable giving by manual Google Scholar search, then asked each tool to find the same papers.

The best tool, Google Scholar Labs, recalled about one third. Most tools, including Perplexity, found fewer than 10. All fifteen tools together found only half. The measure that makes this useful is recall, not just precision: not how many false results did the tool return, but how many real papers did it miss. Elsevier's LeapSpace had a false-positive rate above 70 percent.

The tools did find some replications the manual search had missed, because those papers used different terminology. And longer prompts with examples did not improve results.

This kind of evaluation requires doing the manual search first, which is exactly the work researchers are hoping to avoid. Bekkers did that work. The dataset, prompts and code are on OSF.
