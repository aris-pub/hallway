Eight days before the Riemann Hypothesis claim, Kevin Buzzard (Imperial College London) posted four questions to ask about any AI-generated Lean proof: does the formal statement match the informal one, does the code compile, does the proof prove the statement as written, and does it rely on a bug in Lean's kernel.

When Levent Alpöge released a claimed proof of the Generalized Riemann Hypothesis as about 17 million lines of Lean code with no paper, the Lean and Mathlib communities answered those questions within a day. Two independent tools confirmed that the proved theorem matches the statement of the Riemann Hypothesis that was already in Mathlib, and several independently written checkers accepted the proof.

Software can now answer the last three questions. The first one still depends on people: the Mathlib statement was written and reviewed by experts before this proof existed. For a proof that nobody can read, that reviewed statement is the part of the result that readers have to rely on.

Mathematicians will still want to understand the proof, and Scott Aaronson expects that to take years.
